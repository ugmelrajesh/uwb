# WeighBridge Pro (Streamlit)

Deploy: push this folder to GitHub, then share.streamlit.io > New app > main file `app.py`.
Run locally: `pip install -r requirements.txt && streamlit run app.py`.
Default PIN: 1234 (change under Management > Security).
Data: SQLite `weighbridge.db`. Streamlit Cloud disk is ephemeral; use Management > Backup to export/restore.
